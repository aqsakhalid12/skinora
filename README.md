# SKINORA (Next.js App Router + Tailwind)

1. Put the 25 images in `public/images` (exact names, see `src/data/products.js` + `hero-main.jpg`, `bundle-*.jpg`, `og-image.jpg`, `logo-mark.png`).
2. `npm install`
3. `npm run dev` (development) or `npm run build` then `npm start` (production)
4. Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_SITE_URL` to your live URL.
